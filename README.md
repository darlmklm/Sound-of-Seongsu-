# SOUND OF SEONGSU · V3

인터랙티브 사운드 그래픽 프로젝트. `index.html`을 열고 5개 홈 이미지를 클릭해 상세 장면과 사운드를 탐색하세요.

## V3 수정 사항

1. 홈 카드에 나타나던 검정 글자/호버 레이블을 완전히 제거했습니다. 클릭 영역에는 접근성 이름만 남겼습니다.
2. 홈 카드의 배치와 크기를 사용자가 첨부한 `Home.png`(1728 × 1117)를 기준으로 고정했습니다. 각 이미지는 기준 좌표에서 약 10px 내외로만 천천히 미세하게 진동하며, 충돌 시에도 원래 자리로 복귀합니다.
3. 우측 상단 EXIT는 사용자가 제공한 구형 문 모양의 색상별 SVG 아이콘으로 재구성했습니다.
4. 카페거리의 창문 패턴은 9개 열을 패널 중앙에 정확히 정렬하고, 마우스를 올린 창문이 세로축을 기준으로 열리도록 했습니다.
5. 성수역 2호선의 계단 패턴은 원본의 연속된 지그재그 띠, `0 → 1 → 2 → 3 → 2 → 1`의 6단계 순환 구조로 재구성했습니다. 자동 상승 속도는 기존의 정확히 절반입니다. 스크롤할 때 위아래로 이동하며 무한 반복합니다.
6. 모든 페이지의 임시 합성 사운드를 재제작했습니다. 특히 카페에는 서로 말하는 목소리를, 수제화거리에는 큰 금속 타격음과 소형 기계음을 넣었습니다.
7. 수제화거리 별 그래픽은 사각형 프레임 밖에도 발생하며, 소리의 피크가 높을 때 화면 절반에 달하는 큰 별이 등장합니다. 화면을 클릭하면 큰 별이 추가됩니다.

## 설치 없이 테스트

`SOUND_OF_SEONGSU_V3_TEST.html`을 내려받아 Chrome에서 더블클릭해 실행하세요. 단일 HTML 안에 이미지와 사운드가 포함되어 있습니다.

## GitHub Pages 배포

이 폴더 안의 파일(`index.html`, `style.css`, `app.js`, `assets`)을 저장소 **루트**에 업로드하세요. GitHub > Settings > Pages에서 Deploy from a branch / main / root를 선택합니다.

## 사운드 고지

포함된 오디오는 **실제 서울숲/성수 현장 녹음이 아니라** 분위기를 테스트하기 위해 합성한 데모입니다. 카페/거리 대화는 TTS 합성 영어 음성이므로, 최종 발표 전 직접 녹음한 현장 소리로 교체하면 좋습니다. 사운드 교체 시 `assets/audio/*.mp3`를 같은 이름으로 바꾸면 연결됩니다.

## 사용 방법

- 홈: 사진 클릭 -> 각 장소 진입
- 공통: 우측 상단 문 아이콘 -> 홈으로 돌아가기, `Esc` 가능
- 서울숲: 물의 분출/잔물결 감상, 클릭 시 추가 파문
- 연무장길: 대화/큰 소리에 삼각형 생성, 클릭 시 추가
- 성수역: 지그재그 계단이 천천히 상승, 마우스 스크롤로 위아래 이동
- 수제화거리: 타격음에 반응하는 다양한 크기의 별, 클릭 시 큰 별 등장
- 카페거리: 창문 플랩 자동 모션, 마우스 호버 시 해당 창문 열림

## 실행

Chromium 기반 브라우저에서 `index.html`을 열어 확인하세요. 로컬 서버가 필요하면 `python3 -m http.server 8000` 실행 후 `http://localhost:8000`에 접속하세요.
